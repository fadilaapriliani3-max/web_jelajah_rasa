JELAJAH RASA PALU - WEBSITE 3 HALAMAN

ISI WEBSITE
1. index.html   : halaman Beranda
2. kuliner.html : halaman Pilihan Kuliner
3. tentang.html : halaman Tentang
4. css/style.css: pengaturan tampilan dan responsif
5. js/script.js : fungsi tombol menu pada layar kecil

CARA MENJALANKAN DI WINDOWS
1. Ekstrak file ZIP.
2. Buka folder jelajah_rasa_palu.
3. Klik dua kali file index.html, atau klik kanan lalu pilih Open with > Chrome.
4. Gunakan menu navigasi untuk berpindah ke tiga halaman.

CATATAN UNTUK PENGERJAAN TUGAS
- Website ini merupakan contoh awal yang perlu kamu pelajari dan sesuaikan sendiri.
- Ubah kalimat, warna, susunan bagian, dan isi sesuai ide serta pemahamanmu.
- Ganti alamat email contoh di halaman Tentang dengan alamat yang benar jika diperlukan.
- Website memakai HTML, CSS, dan JavaScript sederhana; tidak membutuhkan database atau instalasi Python.
- Font Google dapat membutuhkan koneksi internet; jika offline, website tetap tampil dengan font pengganti.
